# CHAGent (ACSAC'26, paper 186) — Python dependencies

# PINNED to the authors' evaluation environment: Python 3.12.13 on Linux with a
# CUDA 12.8 capable NVIDIA driver. These are the exact versions that produced the
# reference logs under claims/*/eval_logs/. Installing newer majors (e.g.
# transformers 5.x, which changes the default dtype used by from_pretrained) can
# alter generation behaviour and therefore the reported metrics.

# NOTE:
#   * `torch` is installed separately by install.sh so the correct CUDA build is
#     selected; the pin below is the version install.sh installs (the PyPI wheel
#     for 2.8.0 bundles the CUDA 12.8 runtime, as used by the authors).
#   * `flash-attn` is NOT listed here: no script in this artifact requires it,
#     and it must be built with --no-build-isolation against an already-installed
#     torch. install.sh skips it unless FLASH_ATTN=1 is set.
